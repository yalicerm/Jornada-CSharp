# 🎮 C# Learning Journey | GUI, POO, SQL & Gamificação

Bem-vindo(a) ao meu repositório de estudos de C#! Este espaço é dedicado à minha evolução prática na linguagem, com um foco especial em criar aplicações interativas, aplicar boas práticas de design de software e tornar a experiência do usuário mais engajadora.

## 🎯 Objetivo do Repositório
Documentar e organizar minha evolução prática rumo ao mercado de trabalho como desenvolvedora de software, traduzindo conceitos abstratos em aplicações visuais e interativas. Como estudante com forte base em modelagem de sistemas e bancos de dados, estou utilizando este repositório para solidificar a construção de aplicações completas.

## 📚 Focos de Estudo

- **POO (Programação Orientada a Objetos):** Aplicação prática de conceitos fundamentais como Herança, Polimorfismo, Encapsulamento e Abstração em C#. Aprofundando a forte base lógica orientada a objetos que venho construindo.
- **GUI (Graphical User Interface):** Desenvolvimento de interfaces gráficas intuitivas e funcionais. O objetivo aqui é sair da tela do console e criar aplicações reais com as quais os usuários possam interagir visualmente.
- **Gamificação:** Implementação de mecânicas de jogos (sistemas de pontuação, recompensas, desafios e progressão) para tornar aplicações de uso cotidiano mais dinâmicas, divertidas e focadas no engajamento do usuário.
- **Usando Banco de Dados:** Usando os pacotes MySQL disponíveis no Visual Studio para treinar códigos com banco de dados com foco em busca, inserção, modelagem e manipulação de dados.

## 📂 Estrutura de Projetos

*   `\POO_Fundamentos`: Exercícios focados em modelagem de classes, interfaces, e manipulação de coleções de dados.
*   `\Interfaces_Graficas`: Projetos focados em design de telas, manipulação de eventos de clique e controle de fluxo visual.
*   `\Projetos_Gamificados`: Mini-jogos e aplicações gamificadas demonstrando controle de estado e lógica de recompensa.

## 🛠️ Tecnologias e Ferramentas
*   C#
*   Windows Forms / WPF / .NET MAUI (Conforme a tecnologia gráfica escolhida)
*   Visual Studio
*   Princípios de Design de Software e UML
*   Integração com MySQL
  

## 🚀 Próximos Passos
Continuar expandindo este repositório com projetos cada vez mais complexos, possivelmente integrando esses sistemas interativos com bancos de dados relacionais (como MySQL) para gerenciar e criar aplicações robustas de ponta a ponta.
